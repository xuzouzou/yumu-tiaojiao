# 榆木调酒 YuMu TiaoJiu

一款开源的 iPhone 鸡尾酒酒谱 App（SwiftUI 原生，iOS 17+）。

## 功能

- **61 款经典酒谱**：IBA 经典为主，含尼格罗尼、马天尼、莫吉托、玛格丽特等，附中文讲解、装饰物与分步做法
- **我的酒柜**：勾选你拥有的原料，自动算出「现在就能调」的酒谱，以及「只差一样」的解锁清单
- **按原料搜酒**：搜酒名、口味标签或原料名都行；可按基酒筛选（金酒 / 伏特加 / 威士忌 / 朗姆 / 龙舌兰 / 白兰地 / 起泡酒 / 无酒精）
- **份数换算**：配方详情里 1–4 份一键缩放液体用量
- **今晚喝啥**：随机抽一杯，终结选择困难（可限定只从能调的里面抽）
- **采购清单**：缺的原料一键加入清单，买到了自动进酒柜
- **收藏**：爱心收藏常用酒谱
- 含 4 款无酒精特调；数据全部本地存储，无需联网

## 设计借鉴

功能思路借鉴了 GitHub 上的开源鸡尾酒项目（soffes/bar 的内置酒单、jmduke/Barback 的酒柜概念、BramDC3/Cocktailr 的按原料找酒），代码与配方数据为本项目原创整理，配方规格以 IBA（国际调酒师协会）公开标准为准。

## 安装

未签名 IPA 通过 GitHub Actions 云端 macOS 构建，在仓库 Actions 的 `Build IPA` 运行里下载 `YuMuTiaoJiu-unsigned-ipa`，再用 SideStore 以自己的 Apple ID 签名安装。
